"ДВАДЦЯТИЙ КИЇВ: крізь епохи"
Інтерактивний вебпутівник містом, який оживляє історію Києва ХХ століття на мапі та поєднує геопросторову аналітику й відкриті дані.
Це застосунок, що перетворює прогулянку містом чи вивчення історії на інтерактивне дослідження.
**Для киян та туристів:** можливість дізнатися про знакові історичні події поруч у реальному часі прямо зі смартфона.
**Для школярів та студентів:** наочний інструмент для вивчення історії ХХ століття через географію рідного міста та осмислення зв'язку минулого із сучасною незалежною Україною.
Основний функціонал

1. **Вибір епохи:** інтерактивний часовий повзунок для фільтрації подій за історичними періодами ХХ століття.
2. **Взаємодія з мапою:** користувач може поставити точку в будь-якому місці в межах Києва.
3. **Інформаційна картка події:** на бічній панелі миттєво відображаються:
   * точна дата та історична епоха;
   * змістовний опис події;
   * контекст актуальності для сьогодення;
   * перевірене джерело інформації
